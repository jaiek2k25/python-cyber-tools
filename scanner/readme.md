# 🐍 Python TCP Port Scanner

A simple TCP port scanner written in Python for learning **networking and cybersecurity fundamentals**.

## 📌 Features

- TCP port scanning
- IP address / hostname resolution
- Custom port ranges
- Connection timeout
- Basic error handling
- Command-line interface

## 🛠️ Technologies

- Python 3
- `socket`
- `argparse`

No external Python libraries are required.
